===================================================================
                  5 RAIN PARTICLE EFFECTS PACK (URP)
===================================================================
Thank you for downloading! This package provides 5 lightweight, 
ready-to-use rain particle effects for Unity (Tested on Unity 6.4.9f1).

-------------------------------------------------------------------
1. PIPELINE COMPATIBILITY
-------------------------------------------------------------------
This pack is built specifically for the Universal Render Pipeline (URP).
All materials and prefabs use URP-compatible particle shaders.

-------------------------------------------------------------------
2. INCLUDED PREFABS & EFFECTS
-------------------------------------------------------------------
Located in Assets/ADR_Textures/Content/Prefabs/URP/

- PFX_Rain_Drizzle   : Gentle, light rainfall
- PFX_Rain_Mist      : Soft atmospheric moisture
- PFX_Rain_HeavyMist : High-density fog and mist
- PFX_Rain_Downpour  : Heavy vertical rainfall
- PFX_Rain_StormWind : High-speed wind-blown rain

-------------------------------------------------------------------
3. FOLDER STRUCTURE
-------------------------------------------------------------------
Assets/
└── ADR_Textures/
    ├── Content/
    │   ├── Materials/
    │   │   └── URP/         (5x URP Materials)
    │   ├── Prefabs/
    │   │   └── URP/         (5x URP Rain Prefabs)
    │   └── Textures/        (Rain Alpha Texture)
    ├── Demo_Scenes/         (URP Demo Scene)
    └── Documentation/       (User Guide & Readme)

-------------------------------------------------------------------
4. QUICK START
-------------------------------------------------------------------
1. Open the demo scene located in:
   Assets/ADR_Textures/Demo_Scenes/
2. Go to Assets/ADR_Textures/Content/Prefabs/URP/
3. Drag any rain prefab directly into your scene hierarchy.
4. Position the particle system above your player camera or level.
